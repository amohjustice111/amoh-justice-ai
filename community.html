Quick answers

Frequently asked questions

How do I save my projects?

Use the save option available in a tool, then open My Account or the gallery. Some features save in this browser; cross-device private project syncing requires a configured Supabase account and database.

Can I use the website on my phone?

Yes. The pages are designed to adapt to phones, tablets, and computers. If something looks incorrect, tell support which page and device you are using.

What if a tool does not work?

Refresh once, check your connection, and try again. If it continues, use WhatsApp support and include the page name and the message you see. Never send your password or secret API keys.

Are all generation tools free?

Website navigation, guides, and local preferences do not require paid credits. Some generation services may need a separately configured model or provider; do not assume generation is available until it has been tested.

Can other users see my notes here?

No. Notes and preferences on this page are stored in this browser only. This is not a shared community feed. Shared posts and comments would need a dedicated backend with access controls and moderation.
