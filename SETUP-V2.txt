AMOH JUSTICE AI 2.0 — SETUP NOTES
=================================

WHAT WORKS WITHOUT SETUP
- Black-and-gold cinematic website theme and responsive page layouts.
- AI Creator Studio prompt builder for video and image concepts.
- Copying and saving prompts in the current browser.
- Portfolio filters and saving project notes locally.
- AI Academy lessons and local progress tracking.
- External links to AI tools. Each provider has its own terms, login requirements, free limits and regional availability.

IMPORTANT FREE-USE LIMITATION
This repository does not contain a direct, unlimited video/image generation engine. No dependable promise of unlimited free API generation can be made. The Studio prepares prompts and opens external providers; free plans and credits can change. The existing Justice AI chat also requires its Gemini key to be configured and is subject to the provider's free quota. No paid service is enabled by this setup.

OPTIONAL FREE ACCOUNT SETUP (SUPABASE)
1. Create a Supabase project and check the current free-tier limits and terms.
2. In the Supabase SQL Editor, run the contents of supabase-schema.sql.
3. In the project's Auth settings, configure the site URL to your deployed website URL and set the allowed redirect URLs, including https://YOUR-DOMAIN/account.html.
4. In Vercel project Settings > Environment Variables, add:
   SUPABASE_URL = your project URL
   SUPABASE_ANON_KEY = your project's public anon key
   Do NOT add the service_role key. Never expose service-role keys in a browser or this public config endpoint.
5. Redeploy the site, then open /account.html and test sign-up, email confirmation, sign-in, password reset, sign-out, and private project access.
6. Ensure RLS remains enabled. The SQL policies allow each authenticated user to access only rows whose user_id matches their own user ID.

OPTIONAL JUSTICE AI CHAT
The existing /api/chat endpoint requires GEMINI_API_KEY in Vercel. Use the provider's official console and confirm current pricing, free quota, terms, and model availability before adding the key. Never commit keys to GitHub.

KIE AI REAL VIDEO GENERATION (NEW)
1. Create/manage your API key at https://kie.ai/api-key and check current model pricing at https://kie.ai/pricing. Video generation consumes KIE credits.
2. In Vercel > Project Settings > Environment Variables, add KIE_API_KEY with your secret KIE key. Never paste it into GitHub, the browser, or ChatGPT.
3. Configure SUPABASE_URL and SUPABASE_ANON_KEY as described above. The video API requires a valid signed-in Supabase user so strangers cannot freely spend your KIE credits.
4. Redeploy the project. Open /account.html, create an account, sign in, then go to /studio.html and choose Video prompt > Generate my video prompt > Generate real video with KIE.
5. The Studio submits a Wan 2.2 Turbo 720p task and polls KIE for its result. KIE-generated media links may expire; download important results promptly.
6. If generation fails, check KIE credits/logs, Vercel function logs, Supabase environment variables, and current KIE model documentation. Model parameters and pricing can change.

AI GENERATION INTEGRATION
Do not put provider secrets in client-side code. The Creator Studio uses a server-side API route for KIE and requires an authenticated user. External provider links remain available as alternatives.

CONTACT FORM
The existing contact form still uses the placeholder amohjustice@example.com. Replace it with the intended contact email before publishing, or change the form to a real configured form endpoint.
